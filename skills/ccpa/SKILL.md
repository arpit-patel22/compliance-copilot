# CCPA Analysis Procedure

STEP 1 - Call search_clauses with these keywords:
personal information, consumer, sale, opt-out, delete, disclose, share, rights

STEP 2 - Evaluate each matching clause against these requirements:
- Right to delete personal information disclosed? (S1798.105) - denied or absent = HIGH
- Opt-out of sale/sharing of personal information offered? (S1798.120) - absent = HIGH
- Right to know / access personal information acknowledged? (S1798.100) - absent = MEDIUM
- Purpose limitation stated for collected data? - "any purpose" = MEDIUM
- Non-discrimination for consumers exercising rights mentioned? (S1798.125) - absent = LOW

STEP 3 - For each finding, cite the section EXACTLY as written above (e.g., "CCPA S1798.105"), assign risk HIGH/MEDIUM/LOW, and write a one-line fix.
